# Adapt pinned third-party Skill content as CDF Built-in Skills

CDF adapts selected static guidance from third-party Skills into version-pinned Built-in Skills, retaining upstream provenance and required license notices while owning the resulting behavior, security, testing, and upgrades. CDF does not depend on runtime installation of the upstream repositories and excludes unrelated scripts, external services, broad tool permissions, and automatic upstream updates, because stable offline behavior and compatibility with CDF's domain contracts outweigh verbatim reuse.
