# Runtime Stream Projection is pure

## Status

Accepted

`runLLMChat` was a ~680-line single function interleaving six concerns: think-tag filtering with text backpressure, four concurrent async iterators racing each other (with a comment admitting a deadlock hazard in the subagent taskId waiters), a promise-based taskId correlation subsystem, three-level delegated-task result parsing, approval interrupts with bare `BEGIN`/`COMMIT` transactions, and DB persistence sprinkled with per-token property-dump logging. The module was deep — deleting it would scatter four interleaved protocols to the callers — but had no internal seam, and its 25 tests faked LangGraph stream shapes to reach inside, locking the internal structure while leaving the actual concurrency untestable.

The stream-translation core now lives in `src/main/runtime-stream-projection.ts` as a pure function, mirroring the renderer's Conversation Runtime Projection discipline (ADR-0005/0006): `projectRuntimeStream(state, event, deps) -> { state, events, effects }`. The shell serializes everything the runtime produces — message reasoning/text tokens, tool call boundaries and outputs, subagent stream deltas, accumulator callbacks, turn ends, aborts — into a total order of tagged `RuntimeStreamEvent`s and feeds them to the core one at a time. JavaScript's single-threaded dispatch makes the serialization free: each producer forwards what arrives, decisions all happen in the core.

Everything stateful about the stream protocol is core state: think-tag open/close bookkeeping, text backpressure while a reasoning source is still streaming, the at-most-once buffered-reasoning drain, per-turn sent-text/sent-reasoning flags for the turn-end backfill, the slug-to-taskId correlation for delegated tasks, and the model-triggered skill-attribution dedup set. The promise-waiter machinery that existed to bridge two concurrent iterators — and the deadlock class its comment warned about — is structurally gone: in a total order, correlation is a map lookup.

Impurity is contained in an explicit `deps` record, same as the renderer projection's `deps.now()`: draining the stream accumulator's captured reasoning, taking fallback text, looking up an agent's display name, and generating ids. In tests these are fixed fakes; the event-sequence tests enumerate concurrency interleavings as plain arrays — the backpressure orderings, the subagent-before-task and task-before-subagent arrivals, the aborted-mid-reasoning dangling think block — which no amount of fake stream objects could previously reach.

I/O stays in the shell: `webContents.send` for the produced events, DB writes as core-emitted effects (`upsert-tool-call`, `update-tool-call`, `update-run`, `clear-accumulator-text`), and three control effects (`await-approval`, `continue-turn-loop`, `stop-turn-loop`) that drive the shell's turn loop. The approval persistence block kept its bare `BEGIN`/`COMMIT` verbatim by explicit decision — upgrading it to `db.transaction()` changes rollback semantics on error paths and belongs to a separate change. Todos deduplication also stays in the shell: it is self-contained I/O with no coupling to the stream protocol.

The 25 pre-existing `llm.test.ts` cases were kept untouched as the behavior safety net through every step of the extraction; the projection's own event-sequence tests are the new seam. Per-token property-dump `console.log`s were deleted outright; the remaining lifecycle warnings moved to the shared logger.
